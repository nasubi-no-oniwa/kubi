# 首が飛鳥

645年、飛鳥。音が鳴ったら、斬れ。蘇我入鹿の首は、どこまで飛ぶ。なすびのお庭の作品です。

- 遊ぶ：https://nasubi-no-oniwa.com/kubi/
- ゲーム本体は nasubi-site リポジトリの `kubi/` フォルダにあります（nasubi-no-oniwa.com で公開）
- このリポジトリはランキングのルール用：`database.rules.kubi.json` を上げると自動で otokonoji の `kubi` の部分だけに反映（鍵は Secrets の `OTOKONOJI_SERVICE_ACCOUNT`。ほかのゲームのルールはそのまま残す）
- モデル（板蓋宮・人物・剣・首塚など）は Blender の `tools/make_models.py` で作っています
- 地図は dataofjapan/land（国土地理院の地球地図日本がもと）の県の形を、近畿〜関東だけ粗くして使っています
